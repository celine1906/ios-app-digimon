# Digimon iOS App

A simple iOS application that displays a list of Digimon with pagination, search, filtering, and detail views. The app is implemented using UIKit with MVVM architecture.

## Features
- Paginated Digimon list
- Search by name, level, type, attribute, and field
- Filter (Level, Type, Attribute, Field)
- Digimon detail view
- Favorite Digimon
